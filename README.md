# ShrimpWatch 🦐

**Креветочная разведка**: интерфейс на React + Vite и плановая проверка цены королевских креветок.

## Запуск сайта локально

```bash
npm install
npm run dev
```

Сборка для публикации: `npm run build`.

## Мониторинг цены

GitHub Actions workflow `.github/workflows/price-watch.yml` проверяет публичную страницу товара каждый час (примерно в 17 минут каждого часа по UTC). Запуск также доступен вручную через **Actions → ShrimpWatch price check → Run workflow**.

Уведомление по email отправляется, когда цена впервые опускается ниже **40 грн за 100 г**. Повторные письма не приходят каждый час, пока цена остаётся ниже порога; новое уведомление придёт, если цена вернётся к 40 грн или выше, а затем снова упадёт ниже 40 грн. Последняя цена и время проверки сохраняются в `data/price-state.json`.

## Настройка почтовых уведомлений

Откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- `SMTP_HOST`: SMTP-сервер почтового провайдера
- `SMTP_PORT`: обычно `465` для SSL или `587` для STARTTLS
- `SMTP_USER`: имя пользователя SMTP
- `SMTP_PASS`: пароль или пароль приложения
- `ALERT_EMAIL`: адрес получателя уведомлений
- `SMTP_FROM`: необязательный адрес отправителя, по умолчанию используется `SMTP_USER`

Для Gmail используется `smtp.gmail.com`; при необходимости создайте пароль приложения. Не добавляйте почтовые пароли в исходный код.

Письма будут отправляться только после настройки SMTP-секретов. GitHub Actions должен иметь разрешение на запись содержимого репозитория, поскольку плановая задача сохраняет новое состояние цены.

## Ограничения

- Проверяется публичная страница товара, а не подтверждённое наличие в конкретном магазине.
- Если разметка страницы изменится, проверка завершится ошибкой в журнале workflow, а не будет придумывать цену.
- GitHub Actions может запускать плановую проверку с задержкой, поэтому это не гарантия проверки ровно по минутам.
- Форма на сайте демонстрационная: введённый email не отправляется и не сохраняется.
- Танцпол работает постоянно. Звуковой сигнал об акции доступен после первого касания экрана или нажатия клавиши, поскольку браузеры ограничивают автозапуск звука.

## API статуса

На Vercel endpoint `/api/status` возвращает последние данные проверки без адреса магазина.
