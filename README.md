# 🦐 ShrimpWatch
### Креветочная разведка · Одесса мама

> **Шоб креветки были королевские, цена человеческая, а настроение такое, будто на Привозе тебе сказали: «Золотце, для тебя сделаем красиво».**

ShrimpWatch следит за ценой королевских креветок в «Сильпо», сохраняет историю проверок и присылает письмо, когда цена падает ниже заданного порога. А заодно тут танцуют креветки, тётя Соня раздаёт комплименты, а для внезапного аппетита припасены рецепты.

🌐 **Сайт:** https://shrimp-watch.vercel.app/  
🛒 **Товар под наблюдением:** [Королевская креветка 40/60 в «Сильпо»](https://silpo.ua/product/krevetka-korolivska-syra-defrostovana-40-60-864122)  
⚙️ **Дежурство разведки:** [GitHub Actions](https://github.com/sunmeat/shrimp-watch/actions)

## 🦐 Шо тут у нас имеется?

- **Мониторинг цены.** GitHub Actions проверяет публичную страницу товара каждый час.
- **Письмо при выгодной цене.** Если цена становится ниже **40 грн за 100 г**, разведка отправляет уведомление на почту.
- **Без почтового тарарама.** Пока цена остаётся ниже порога, письмо не прилетает каждый час. Если отправка не удалась, система попробует снова при следующей проверке.
- **История цены.** Последние проверки хранятся в `data/price-state.json`. Никакого гадания на кофейной гуще.
- **Статус на сайте.** Показываем последнюю полученную цену и статус скидки.
- **Креветочная дискотека.** Жми на танцпол, пусть море знает, как мы празднуем выгодную покупку.
- **100 фактов о креветках.** Биология и морская жизнь без баек с потолка.
- **10 рецептов от тёти Сони.** Чтобы покупка не закончилась вопросом «И шо теперь с этим делать?».
- **Одесская служба заботы.** Комплименты и пожелания, бесплатно и без карты лояльности.

## 💸 Когда креветка считается выгодной?

Главный ориентир: **меньше 40 грн за 100 г**. Автоматическая проверка запускается каждый час примерно на 17-й минуте по расписанию GitHub Actions. Можно запустить её и вручную.

Важный момент: цена считывается с публичной страницы товара. Наличие в конкретном магазине, актуальная цена именно в твоём регионе и возможность немедленно купить товар автоматически не подтверждаются. Перед поездкой проверь карточку «Сильпо». Одесса Одессой, а зря кататься через весь город никто не любит.

## 📬 Как устроены уведомления

Когда цена опускается ниже порога, на почту приходит письмо с темой примерно такой:

> 🦐 Есть скидка! Креветки по 39,99 грн / 100 г

В письме есть текущая цена, обычная цена, если её удалось определить, примерная экономия, время проверки и ссылка на товар. HTML-письмо оформлено по-людски, а не как записка, переданная через кассу.

Повторного письма каждый час не будет, пока цена остаётся ниже порога. Если письмо не удалось отправить, мониторинг повторит попытку при следующем запуске.

### 🧪 Проверить почту отдельным тестом

[**Открыть ручной тест письма →**](https://github.com/sunmeat/shrimp-watch/actions/workflows/test-email.yml)

1. Открой страницу workflow.
2. Нажми **Run workflow**.
3. В меню ещё раз нажми зелёную **Run workflow**.
4. Дождись завершения запуска и проверь почту, включая «Спам».

Тест отправляет демонстрационную цену **39,99 грн** при обычной цене **49,99 грн** и использует **тот же шаблон письма**, что и настоящая акция. Состояние мониторинга и историю цен он не меняет. Сам тест запускается только вручную.

## 🔐 Настроить секреты GitHub Actions

Открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:

| Secret | Что указать |
|---|---|
| `SMTP_HOST` | Адрес SMTP-сервера почтового провайдера |
| `SMTP_PORT` | Порт SMTP: обычно `465` для SSL или `587` для STARTTLS, смотри настройки провайдера |
| `SMTP_USER` | Логин SMTP |
| `SMTP_PASS` | Пароль или пароль приложения |
| `SMTP_FROM` | Адрес отправителя; если не задан, используется `SMTP_USER` |
| `ALERT_EMAIL` | Адрес, куда присылать уведомления |

Для Gmail SMTP-сервер обычно `smtp.gmail.com`; может потребоваться пароль приложения. **Не записывай пароли в код, README, коммиты или публичные Issues.** Секреты на то и секреты, золотце.

У GitHub Actions должно быть разрешение на запись в репозиторий, потому что автоматическая задача сохраняет свежую историю цены.

## 🛠️ Запуск на своём компьютере

Понадобится **Node.js 22 или новее** и npm.

```bash
git clone https://github.com/sunmeat/shrimp-watch.git
cd shrimp-watch
npm install
npm run dev
```

Vite покажет локальный адрес сайта в терминале.

### Собрать сайт

```bash
npm run build
npm run preview
```

### Проверить цену вручную

```bash
npm run watch:price
```

Команда обращается к публичной странице товара и выполняет логику мониторинга. Для отправки письма локально задай переменные окружения `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` и `ALERT_EMAIL`; `SMTP_FROM` необязателен. Без SMTP цена может провериться, но письмо не отправится.

## ⏰ Кто и когда выходит на дежурство?

| Workflow | Расписание | Назначение |
|---|---|---|
| `price-watch.yml` | Каждый час, на 17-й минуте; также вручную | Проверить цену, при необходимости отправить уведомление и сохранить состояние |
| `test-email.yml` | Только вручную | Проверить SMTP и шаблон письма |

Плановые запуски GitHub Actions могут задерживаться. Если магазин изменит структуру страницы, мониторинг может не извлечь цену. В таком случае смотри журнал запуска в разделе **Actions**. Лучше честная ошибка, чем цена, взятая с потолка.

## 🧭 Как всё устроено под капотом

- **React + Vite** отвечают за интерфейс сайта.
- **Node.js** получает страницу товара и извлекает цену.
- **GitHub Actions** запускает периодические проверки и ручные задачи.
- **Nodemailer + SMTP** отправляют уведомления.
- **`data/price-state.json`** хранит последнюю цену, статус и до 180 последних точек истории.
- **`/api/status`** отдаёт данные сайту, который запрашивает обновление примерно раз в минуту.

## 🧾 Честные оговорки, как у порядочного одессита

- Мы следим за одним конкретным товаром, а не за всеми креветками Одессы.
- Цена на сайте может отличаться в зависимости от региона, магазина, наличия и времени.
- Скидка на странице не гарантирует, что товар есть в ближайшем магазине.
- Автоматическое извлечение цены зависит от структуры страницы магазина и может потребовать обновления.
- Письма зависят от доступности GitHub Actions и SMTP-провайдера.
- Звуковой сигнал в браузере включается после первого касания экрана или нажатия клавиши: браузеры не всегда разрешают автозапуск звука.
